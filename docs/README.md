# Filament Form Builder

Forms designed in the panel, rendered on the site with Blade, Livewire, a JSON API or an embed, submissions stored, emailed and exported.

## Features

- **[Builder in the panel](building-forms.md)**: 29 field types, a live preview, JSON import and export.
- **[Conditions and steps](logic-and-steps.md)**: show, hide or require fields based on other answers, and split long forms into steps.
- **[Render it anywhere](rendering.md)**: Blade, Livewire, a JSON API, an iframe or a script embed, all through the same validation.
- **[Submissions in the panel](submissions.md)**: a column and a filter per field, read / unread state, CSV and Excel export, a daily chart.
- **[Notifications](notifications.md)**: emails to you and the visitor, panel notifications, Slack, Discord, Teams and signed webhooks.
- **[Sharing and templates](sharing-and-templates.md)**: private share links you can expire and revoke, twenty templates to start from.
- **[Spam protection without a captcha](spam-protection.md)**: honeypot, time trap, rate limit and blocklists, with Turnstile, hCaptcha or reCAPTCHA when you want one.
- **[Extensible](extending.md)**: your own field types, models and sinks, tenant scoping, testing helpers.
